# NumPy Linear Algebra Visualizer

A Python-based interactive application for performing and visualizing fundamental linear algebra operations.

This project was built to practice Python, NumPy, Matplotlib, and important linear algebra concepts used in Machine Learning and Artificial Intelligence.

---

## Features

### 1. Vector Operations

- Vector Addition
- Vector Subtraction
- Element-wise Multiplication
- Vector Magnitude
- Dot Product
- Unit Vector
- Vector Projection
- Linear Combination
- Linear Independence

### 2. Matrix Operations

- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Transpose
- Determinant
- Matrix Inverse

### 3. Vector Spaces

- Linear Combination
- Vector Space Checks
- Basis Check
- Dimension Calculation

### 4. Linear Transformations

- Scaling
- Rotation
- X-Shear
- Y-Shear
- Custom Matrix Transformation

### 5. Orthogonality

- Orthogonal vector checking using the dot product.

### 6. Eigenvalues and Eigenvectors

- Calculate eigenvalues
- Calculate eigenvectors
- Visualize real eigenvectors in a 2D graph
- Handle complex eigenvalues/eigenvectors

---

## Visualizations

The project uses Matplotlib to visualize:

- Vector Addition
- Vector Subtraction
- Element-wise Multiplication
- Dot Product
- Vector Projection
- Matrix Transformations
- Eigenvectors

Vectors are displayed on a 2D coordinate plane using arrows.
